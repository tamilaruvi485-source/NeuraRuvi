# Student Management Dashboard

A **simple web-based dashboard** to manage student records with dynamic interactivity and data persistence using **JavaScript** and **localStorage**.

---

## 🚀 Project Overview
Small institutes often need basic internal tools to manage student data but lack technical infrastructure. This dashboard provides a lightweight solution to **add, view, update, and delete student records** efficiently.

---

## 🎯 Objective
- Create a functional dashboard to manage student records.
- Ensure **CRUD operations** (Create, Read, Update, Delete) work seamlessly.
- Store data persistently using **localStorage**.
- Optional: Include **filter/search functionality** for easier data access.

---

## ⚙️ Features
- **Add Student**: Insert new student records with fields:  
  - Name  
  - Registration Number  
  - Department  
  - Year  
  - Marks
- **View Records**: Display all students in a neat table format.
- **Update Records**: Edit existing student details dynamically.
- **Delete Records**: Remove student records easily.
- **Optional Filter/Search**: Quickly find student records by name, department, or registration number.

---

## 💻 Technology Stack
- **Frontend**: HTML, CSS  
- **Programming**: JavaScript (for dynamic operations)  
- **Storage**: LocalStorage (browser-based persistence)
